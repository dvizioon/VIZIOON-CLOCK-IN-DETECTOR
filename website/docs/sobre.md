# Sobre

Detector de ponto, versão 1.0.1.

Desenvolvido por Daniel Estevão, Vizioon.

Código e downloads: [dvizioon/VIZIOON-CLOCK-IN-DETECTOR](https://github.com/dvizioon/VIZIOON-CLOCK-IN-DETECTOR). O APK de cada versão é o arquivo anexado na release do GitHub.

O aplicativo observa o TOTVS RH Clock In (`com.clockinfieldtools`) neste aparelho. Os horários ficam num arquivo local do próprio detector. Nada disso é enviado para um servidor.
