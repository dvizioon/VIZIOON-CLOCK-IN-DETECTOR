# Privacidade

O detector pede acesso ao uso para saber qual aplicativo está na frente. Pede notificação para avisar a batida. Pede para aparecer sobre outros aplicativos só se o alerta no meio da tela estiver ligado.

Ele não pede a câmera, não guarda imagem e não lê o reconhecimento facial da TOTVS. A batida é um horário neste celular. Configuração, pontos e observações ficam em arquivos locais do aplicativo.
