# Site — Detector de ponto

Documentação em [Docusaurus](https://docusaurus.io/), no mesmo formato do VIZIOON LAB ENVIRONMENTS.

```bash
cd website
npm install
npm start
```

Abre em `http://localhost:3000/VIZIOON-CLOCK-IN-DETECTOR/`.

Na raiz do projeto, `npm run docs` faz o mesmo.

A página **Versões** lê as releases do GitHub.
